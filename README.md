# cablepunk.net

A reference document for the cablepunk aesthetic: chronology and works.

This document catalogs works that have been deliberately labeled as cablepunk by their creators. The artists and developers documented here are independent of one another. Inclusion does not imply affiliation.

Compiled by Stephen Oravec.
