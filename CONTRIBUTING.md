# Contributing to cablepunk.net

This is a reference document for the cablepunk aesthetic. Contributions that add or correct entries are welcome.

## What belongs here

Works that have been deliberately labeled as cablepunk by their creators. This includes art, fiction, video games, music, film, or any other medium where the creator has explicitly used the word "cablepunk" to describe their work.

Works that merely resemble a cablepunk aesthetic but have not been labeled as such by their creators are not included.

## How to contribute

1. Fork this repository.
2. Make your changes to `index.html`.
3. Submit a pull request with a brief description of what you are adding or correcting.

Alternatively, if you are not comfortable with pull requests, you can open an issue describing the work you would like added, including the artist name, title, year, medium, and a link.

## Link maintenance

If you notice a broken link, please open an issue or submit a pull request with an updated or archived URL.
